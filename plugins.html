GET STARTED

INSTALL ONCE.
KEEP MOVING.

Made for After Effects 2026 on Windows.

  1. Download and extract the ZIP.

    Keep the full Motion Dock folder together.

  2. Run Install Motion Dock.cmd.

    It installs for your Windows account and enables Adobe’s unsigned local extension setting.

  3. Restart After Effects.

    Open Window → Extensions (Legacy) → Motion Dock, then dock the panel.

  4. Get updates from the panel.

    Motion Dock checks for published releases. Use Updates → Install when you’re ready. Local settings, expressions and ROI records stay on that computer.
